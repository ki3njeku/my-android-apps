# Projects
## The first app(Unit converter)
The first app is a simple unit converter that converts inches to centimeters and vice versa. In this project I learnt the basics connecting the user interface created in the xml files with the logic that is stored in the Kotlin file. Here I learnt how to use the id in the xml elements to identify them and assign them to objects in the Kotlin. These objects have properties which can be used in the various logical operations. An example of this is the .text attribute of the EditText object type. This can be extracted and stored to a variable which can be used to perform operations. Another thing that I got from this project is using the setOnClickListener function in the button object type which can be used to perform operations and change the attributes of the button or of other objects such as has been used in the toggle button and the convert button. 
A pattern that I have learnt but not yet completely understood is the way objects are declared as private lateinit variables in the main activity class and initialized later within the onCreate function.

## The fourth app(Country trivia)
This is an app that shows a quiz where the user must pick the country name based on the flag that is shown. The flag images are stored in the drawable folder and their id's are stored in an xml array(To describe later the way I used this). All the flags of all the countries are present and therefore there needs to be a way to pick which country flag to show. The first task was to create an array that mirrors the xml array. The array in the xml is a typed array which has drawables. We use the get typed array function which gets the array and stores it in a variable. We then et the resource ids and store them in an int array and free the typed array. Using the random class we get the flag to be displayed. We then create a list of the other three options which are also picked randomly. A copy list is used to prevent the options from appearing twice. The String version of the flags are stored in a string array which is sadly hard-coded into the Kotlin and which also in the same order as the flags making translation from flag to name simple.
From this I learnt how to properly transfer data from one activity to another, properly using the on checked change listener on the radio group and also how to make a custom drawable resource which i used to create the background for when the answer is correct or wrong. I also fine tuned handling activities using the start activity and finish functions.
